# BranchBase A refinements

Preview concepts generated with built-in image_gen. Original A is style reference. No application implementation changes.

Proposed behavior: collapsed rows expose up to two configured groups and two app links per visible group. Stable configuration order. Explicit +N apps and +N groups menu triggers. Error summaries stay visible without reordering controls. Hover/focus previews metadata; click or keyboard opens persistent action menus. Chevron independently expands. Group name navigates to detail. Agent activity belongs to worktree, not app group. Escape closes menus; return restores list state.

Image limitations: A1 generated an unwanted per-group Agent column and start icon while starting; omit that column and disable duplicate start during operations. A1 title incorrectly says agents running instead of groups running. A2 illustrates the app menu but retained expanded rows instead of the requested fully collapsed background, and mixes a Product Running summary with a Worker dashboard Starting row; derive the summary consistently from actual observations. A3 resource figures, attribution, dependency visualization and per-app log filtering are proposed capabilities, not verified existing behavior. Ready must mean endpoint readiness, not all tests/checks passed. Concept datasets are independent.

Sources: https://linear.app/docs/peek ; https://vercel.com/geist/context-card ; https://vercel.com/geist/tooltip
